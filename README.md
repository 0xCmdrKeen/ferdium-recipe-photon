# Photon for Ferdium

[Photon](https://phtn.app) is an alternative frontend for [Lemmy](https://join-lemmy.org).

Using this recipe will allow you to see the unread notification count (replies & DMs) for the currently logged in account. 

If your favorite instance hosts its own version of Photon and you prefer using that instead of the default, simply change the "Custom server" input to your instance's Photon installation.
